# VT Hash Checker

Небольшая публичная веб-панель для поиска существующих отчётов VirusTotal по MD5/SHA-1/SHA-256.

## Что внутри

- FastAPI backend.
- VirusTotal API v3: `GET /api/v3/files/{hash}`.
- SQLite в локальном persistent volume.
- Кэш результатов и история на 7 суток.
- Ротация логов через `RotatingFileHandler`: 5 файлов по 5 MB.
- Публичная HTML-панель.
- История запросов.
- Комментарии к конкретному хэшу.
- Локальный лимит новых запросов: по умолчанию 20/час.
- API key не попадает в HTML/JavaScript и хранится только в `.env`.
- Один Docker-контейнер.

## Запуск

```bash
cp .env.example .env
# отредактировать .env и вставить VT_API_KEY

mkdir -p data logs
docker compose up -d --build
```

После этого открыть:

http://localhost:8000

SQLite появится в `./data/vt_history.sqlite3`, логи — в `./logs/app.log`.

## Запуск без compose

```bash
docker build -t vt-hash-checker .
docker run --rm \
  -p 8000:8000 \
  --env-file .env \
  -v "$(pwd)/data:/data" \
  -v "$(pwd)/logs:/logs" \
  vt-hash-checker
```

Можно изменить пути внутри контейнера через `DB_PATH` и `LOG_PATH`, но для сохранения данных после удаления контейнера рекомендуется монтировать `/data` и `/logs`.

## Поведение

1. Пользователь вводит hash.
2. Backend нормализует и валидирует MD5/SHA-1/SHA-256.
3. Если свежий результат есть в SQLite, VirusTotal не вызывается.
4. Иначе выполняется `GET /api/v3/files/{hash}`.
5. Результат сохраняется на 7 суток.
6. Ошибки upstream/API сохраняются в истории и пишутся в лог.
7. По результату можно оставить публичный комментарий.
8. Старые записи очищаются при старте и при новых запросах.

## Важное ограничение VirusTotal

Этот проект рассчитан на получение уже существующих отчётов, а не на принудительный rescanning файлов.

VirusTotal Public API в настоящее время ограничен 500 запросами/сутки и 4 запросами/минуту. Public API также не разрешено использовать в коммерческих продуктах или сервисах. Поэтому перед публичным/коммерческим использованием нужно проверить условия VirusTotal и при необходимости использовать Premium API.

Проект дополнительно ограничивает новые upstream-запросы до `REQUESTS_PER_HOUR=20`. Попадание в локальный кэш не расходует запрос к VirusTotal.

## Безопасность

Поскольку панель публичная, перед публикацией в интернет рекомендуется добавить reverse proxy с HTTPS, CAPTCHA/WAF и более строгий per-IP rate limit. Комментарии сейчас не требуют аккаунта и являются публичными.
